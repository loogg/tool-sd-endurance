# 开发启动提示词

在当前项目中，把下面的 Figma 实现为可运行、可静态部署的纯前端 Web 工具：
https://www.figma.com/design/jw3p4QykbgwxkEE9MFQnF4/SD?node-id=78-123

先读取现有项目约定。本次以 Figma 的「00 · 计算依据与数据模型」「01 · 产品界面及原生 Annotation」「02 · 设计系统（交互与动效、布局与自适应）」为依据，并查看关键状态截图；按随附的 ACCEPTANCE.md 验收，不需要再重写一套需求或理论文档。

沿用项目技术栈；空项目自行选择成熟、轻量的方案。架构、组件、图表库和测试工具由你合理选择。产品页各 Section 内是同一模式的状态，R01/R02 只是宽度参考。实现数据驱动的真实输入、计算、预设与帮助，不逐帧建路由，不照搬固定算例跳转或默认值。

模型、单位和业务边界不得擅改；预设参考随附 preset-sources.json，先做小而真实的型号集；保留原指标与来源限定，缺失参数不编造。影响这些含义的冲突需要确认，其余实现细节自行判断。

直接完成实现、启动、真实交互与截图检查、测试和修复回归，直到验收通过。交付源码、静态构建产物、启动/测试/构建命令和简要验收证据；不要仅凭编译成功宣告完成。权限、数据或环境阻塞须具体说明，未执行的检查不得标为通过。不要未经确认发布到外部服务。
