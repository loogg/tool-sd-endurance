## 必须检查

| 范围 | 通过条件 |
|---|---|
| 产品范围 | A 主机写入预算、B P/E 工程估算、D 选型需求，以及图表、计算过程、参数帮助、计算原理、高级设置和具体型号预设均为真实功能；同一模式的各状态由数据驱动，不逐帧建路由。无需后端、桌面壳或日志平台。 |
| 简单输入 | 初始不预填演示数值；D 只填目标年限和日均写入即可计算，候选与高级设置可不填。单位固定展示，用户不用输入 `/day` 等文本。 |
| 计算一致性 | 公式、口径与边界以模型 00 为准；结果、图表、敏感性与计算过程使用同一份未舍入数据。不会把达到预算的时间说成失效日期或保证寿命。 |
| 校验与历史 | 空值、负值、非有限数及溢出正确处理；非法输入就近报错并保留内容。只有明确新卡可采用零历史；历史未知不作现有卡时间投影。q=0 不显示无限寿命；H≥E 显示预算已达到，不判卡损坏。 |
| 重新计算 | 改参数后标记“待重新计算”，旧结果/图表/过程保持同一成功快照；成功提交后一起更新。失败不伪装成新结果。 |
| 状态保留 | 切换模式保留各自数据；往返计算原理、展开可选项不丢输入和结果。重置只清除当前模式。高级设置保存才应用，取消/关闭/Esc 不应用草稿。 |
| 真实预设 | 交付可实际选用的型号/容量记录，自动填已知参数并保留原指标、来源及限制；手改后标记假设。不能用分类默认值、系列最高值摊给其他容量或用录像小时冒充 Host TBW。某类别无适用资料可明确说明，但不能以空下拉或假记录冒充完整预设功能。 |
| 交互与可访问性 | 键盘可完成主任务；焦点可见，弹层打开/关闭及焦点返回正确。字段有可访问标签，错误和新结果可被感知；帮助可开/关/再次打开并跳转原理。图表关键数值同时有文字表达。 |
| 视觉与自适应 | 实际打开并操作成品，对照桌面及02中的R01/R02检查1440、1024、320 CSS px，并覆盖实现断点两侧；200%文本放大另测。不裁切、重叠、整页横向滚动或缩小字号迁就布局；缩放不丢输入/结果。图表按容器重绘，窄屏导航、长公式与帮助/高级弹层均可读可操作；减少动效时无非必要动画。 |
| 构建与交付 | 从干净安装运行项目，构建产物可由静态服务器正常使用。相关回归与新增测试、类型/静态检查通过；无核心流程运行异常，不上传用户输入。交付源码、构建产物、操作命令及检查证据。 |

预设可从随附 `preset-sources.json` 的两条来源记录起步。记录被核对不等于已具备全部计算参数；保留其中的缺项与使用限制，不自动升级证据状态。

## 最小计算回归

以下是模型 00 的算例及同公式推导的回归值，不是产品预设。E为主机预算、H为累计主机写入、q为日均写入、R为剩余主机预算。自动测试比较未格式化结果，使用合理浮点容差，显示最后才舍入。

| 场景 | 输入 | 预期 |
|---|---|---|
| A 已用卡 | E=128 TB，H=18.5 TB，q=35 GB/天 | R=109.5 TB；3128.571428…天；显示约8.6年。 |
| A 重新计算 | 上例只把q改为70 | R仍109.5 TB；1564.285714…天；显示约4.3年。 |
| A 新卡 | 明确新卡，E=128，q=35 | H=0；R=128 TB；3657.142857…天。 |
| D 无候选 | q=35 GB/天，Y=5年 | 需求63.875 TB；无候选阈值或余量。 |
| D 有候选 | 上例增加全新候选128 TB | 需求不变，候选余量64.125 TB。 |
| B 工程估算 | C=32 GB，P/E=3000，N_used=38.4 TB，WAF_future=2，q=35 | R=28.8 TB；822.857142…天；显示约2.3年。 |
| B 历史估算 | Host历史9.6 TB，WAF_past=4，未来WAF=2；其他同上 | N_used=38.4 TB；不能把未来WAF套到历史，R仍28.8 TB。 |

另外覆盖：零负载、未知历史、预算超限、单位换算、非有限输入及无效提交。增加几组非演示参数，确认结果不是硬编码。
